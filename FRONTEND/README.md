# 🌲 MVP Front-End: Terê Verde Online

![Logo do Projeto](/FRONTEND/img/LOGO%20FINAL%20SEM%20FUNDO%20menor.png)

Este projeto é um MVP (Minimum Viable Product) de front-end desenvolvido como parte da discplina MVP FRONT-END DEVELOPMENT do curso de Análise e Desenvolvimento de Sistemas. O objetivo é criar uma plataforma digital que centraliza informações turísticas (trilhas, cachoeiras, eventos e condições) sobre as três principais unidades de conservação de Teresópolis, RJ.

---

## 🎯 Situação-Problema Escolhida

A situação-problema é a **Circuito Terê Verde**. O desafio é desenvolver um website que simplifique o processo de consulta sobre biodiversidade, trilhas, eventos e condições das atrações naturais para visitantes dos parques de Teresópolis:

* Parque Nacional da Serra dos Órgãos (PARNASO)
* Parque Estadual dos Três Picos (PETP)
* Parque Natural Municipal Montanhas de Teresópolis (PNMMT)

---

## 🚀 O MVP

Este MVP de front-end oferece uma experiência de usuário (visitante) completa e informativa, utilizando apenas HTML, CSS e JavaScript. O projeto é totalmente estático, sem necessidade de back-end.

### Funcionalidades Implementadas

* **Navegação Multi-página:** Um site coeso com várias páginas (Home, Trilhas, Cachoeiras, etc.).
* **Abas (Tabs) com JavaScript:** As páginas de detalhe dos parques (`parque.html`, `petp.html`, `pnmmt.html`) usam JavaScript para alternar o conteúdo entre "Sobre", "Informações" e "Trilhas".
* **Layout Moderno:** Uso de transparência, Flexbox e Grid para criar uma interface moderna.

---

## 🎨 Prototipação

O desenvolvimento visual do projeto passou por duas etapas de prototipação para garantir a melhor experiência de usuário:

* **Baixa Fidelidade:** Criado utilizando Paint, focado na estrutura básica e disposição dos elementos.

* **Média Fidelidade:** Desenvolvido no Figma, detalhando o design, cores, tipografia e fluxo de navegação.

---

## 💻 Tecnologias Utilizadas

* **HTML5:** Para a estrutura semântica de todas as páginas.
* **CSS:** Para estilização moderna, responsividade, transparência e layouts complexos.
* **JavaScript:** Para toda a interatividade do site:
    * Funcionalidade das abas (tabs) nas páginas dos parques.

---

## 🏃‍♂️ Como Executar o Projeto

Este é um projeto de front-end estático. Não é necessário nenhum servidor, build ou instalação de pacotes.

1.  **Clone este repositório:**
    ```bash
    git clone (https://github.com/projetomvp15-blip/MVP-Tere-Verde.git)
    ```
2.  **Navegue até a pasta do projeto:**
    ```bash
    cd MVP-Tere-Verde
    ```
3.  **Abra o arquivo principal no seu navegador:**
    Basta dar um duplo-clique no arquivo `index.html`.

4.  **Abra o arquivo do administrador no seu navegador:**
    Basta dar um duplo-clique no arquivo `admin-login-page.html`.
